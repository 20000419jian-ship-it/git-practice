# 我的练手项目：版本A 👋

这是我学习 Git / GitHub 流程的第一个项目。

## 这个项目是什么

一个简单的个人介绍网页（纯 HTML + CSS + JS，无需安装任何东西），
用 `index.html` 打开就能看。

## 我要练的 Git 流程

1. 修改文件 → `git status` 查看变化
2. `git add` 暂存 → `git commit` 提交
3. 在 GitHub 建仓库 → `git remote add` 关联 → `git push` 推送
4. 制造一次冲突 → 手动解决 → 再提交（进阶）

详细练习步骤见 [EXERCISES.md](EXERCISES.md)。
